# ByByte-DIY Project Context

## Project

ByByte-DIY is an open robotics education project focused on helping children, students, teachers, makers, and robotics clubs learn electronics, programming, robotics, and engineering.

The project includes:

* ByByte Nano
* ByByte Mega
* ByByte NanoBoy
* robotics courses and assembly guides
* electronics and programming documentation
* educational materials
* open-source hardware and software

## Target Audience

Documentation may be read by:

* children and teenagers
* beginners in electronics and programming
* parents
* teachers
* robotics instructors
* makers
* technically experienced users

Translations must therefore be technically accurate while remaining clear and accessible.

Do not unnecessarily complicate simple explanations.

## Source Language

English is the canonical source language of the documentation.

Translations must preserve the meaning and intent of the English source.

Do not rewrite, expand, shorten, or reinterpret the source unless explicitly requested.

## Brand and Product Names

The following names are proper names and must not be translated:

* ByByte-DIY
* ByByte
* ByByte Nano
* ByByte Mega
* ByByte NanoBoy
* Arduino
* Arduino Nano
* Arduino Mega
* ESP32
* ESP32-CAM
* Ottoblockly
* GitHub
* Discord
* YouTube

Preserve the original capitalization of product names, technologies, protocols, libraries, and software.

## Translation Priorities

Apply these priorities in order:

1. Preserve technical meaning.
2. Preserve Sphinx and reStructuredText syntax.
3. Preserve code, identifiers, placeholders, references, and URLs.
4. Use natural language in the target language.
5. Maintain terminology consistently across the entire project.
6. Preserve the tone and educational level of the source.

When literal translation conflicts with technical accuracy or natural language, prefer the technically correct and natural equivalent while preserving the original meaning.
